hermes-openwrt

A signed feed carrying hermes-agent and luci-app-hermes: the Hermes Agent as a native OpenWrt service. The reference devices are the GL.iNet Flint 2 and Brume 2; generic 64-bit ARM is served too.

OpenWrt 25.12 and later

wget -O /etc/apk/keys/hermes-openwrt.pem \
  https://taipanbox.github.io/hermes-openwrt/hermes-openwrt.pem

echo "https://taipanbox.github.io/hermes-openwrt/25.12/$(cat /etc/apk/arch)/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list

apk update && apk add hermes-agent luci-app-hermes

Without the key, apk drops the repository silently and the package simply does not exist; no --allow-untrusted appears anywhere above. OpenWrt 24.10 is not served.

Architectures: aarch64_cortex-a53 aarch64_generic
